# CookieBox 主界面重构 · 设计理念（T-019）

> 范围：`activity_main.xml` + 新增资源（颜色 / 尺寸 / 两个 shape）+ 深色主题。**未改动任何 Kotlin 代码**，全部 ViewBinding id 保留。

## 一句话

**让网页成为主角，把浏览器收成两颗“浮在内容上的药丸”。** 顶部一颗管“我在哪、安不安全、加载到哪”；底部一颗管“去哪、开了几个、取 Cookie”。

## 1. 顶部 · 智能浮动药丸地址栏

| 元素 | 做法 | 为什么 |
|---|---|---|
| 容器 | `MaterialCardView`，48dp 高、24dp 全圆角，四周 12dp 留白，1dp 发丝描边 + 3dp 轻阴影 | 脱离通栏后，地址栏从“系统框架”变成“可触摸的物件”，这是 Arc Search / Brave 的共同语言 |
| SSL 挂锁 | 30dp 圆形底座 + 15dp 挂锁；颜色沿用现有逻辑（https = 品牌色，搜索 / http = 中性灰） | 安全状态是浏览器第一信息，给它一个固定“座位”，眼睛不用找 |
| 域名排版 | `sans-serif-medium` 15sp，字距 +0.01，单行 | 中粗字重让域名在深色底上依然锐利，字距防止中英文混排挤在一起 |
| 进度条 | `LinearProgressIndicator` 2dp，贴药丸底边，被圆角自然裁切；轨道透明 | 进度“长在”地址栏里而不是另起一条线，加载时不推动布局、不抢视线 |
| 更多菜单 | 收进药丸右端 | 顶部只剩一个物件，视觉重心更稳 |
| 页内查找 | 同款 44dp 药丸，在地址栏下方展开 | 同一语言的第二层，打开 / 关闭都不改变主结构 |

## 2. 底部 · 悬浮胶囊控制底栏

- 60dp 高、30dp 全圆角、左右 14dp、离底 12dp；10dp 阴影 + 发丝描边，深色下阴影不明显时靠描边勾出轮廓。
- 顺序：后退 · 前进 · 主页 · 标签 · 储存库 · **提取**。高频导航在拇指左侧弧线，主行动在右侧拇指最舒服的位置。
- **标签数量角标**：图标右上角 16dp 品牌色小胶囊，外圈 1.5dp 用底栏底色描边，做出“镂空”分离感；>99 时代码显示 ∞。
- **Cookie 提取胶囊**：整栏唯一的实心元素，品牌色 + 图标 + 文字。一眼就知道 CookieBox 和别的浏览器不一样在哪。
- 网页视窗底部预留 78dp（底栏 + 边距 + 6dp 呼吸），底栏浮在背景上而**不遮挡网页内容**——这对“底部有登录按钮 / 同意按钮”的页面很重要。

## 3. 深色模式 · Slate 极简黑

| 角色 | 色值 | 说明 |
|---|---|---|
| 底色 | `#0F172A` | 带一点蓝的黑，比纯黑柔和，OLED 上不“漏光” |
| 浮层（两颗药丸、卡片） | `#151E31` | 只比底色亮一级，靠描边而不是大色差分层 |
| 发丝边 | `#243045` | 1dp，“细腻卡片边框”的来源 |
| 次级面 | `#1E293B` | 挂锁底座、输入区 |
| 主文字 / 次文字 | `#E2E8F0` / `#94A3B8` | 对比度分别约 14:1 / 6:1，满足 WCAG AA |
| 品牌色 | `#F5B971` | 浅色版的饼干棕在深底上太闷，换成同色相的琥珀 |

- 实现方式：`values-night/colors.xml` **同名覆盖**既有色名（名字不变只换值），底部弹窗等存量界面自动跟随变暗；新增色统一 `cb_` 前缀放在 `colors_ui.xml`。
- `values-night/themes.xml`：状态栏 / 导航栏改为底色 + 浅色图标；底部弹窗父主题改为非 Light 版。
- 浅色模式保持原有饼干色系，只获得新的形态（药丸、描边、悬浮）。

## 4. 兼容性

- 保留全部 id。类型变化均安全：`progressBar` → `LinearProgressIndicator`（是 `ProgressBar` 子类），`layoutFindBar` / `bottomAppBar` → `MaterialCardView`（代码只用到 visibility 与 Snackbar anchor）。
- 不新增依赖（Material 1.11.0 已含所需组件）；不碰存储、不碰 JS 注入、不碰 CI。

## 5. 后续可选（需改 Kotlin，另开任务）

1. 进度平滑动画：`binding.progressBar.setProgressCompat(newProgress, true)` 替换 `progress =`。
2. 非编辑态只显示域名（如 `github.com`），聚焦时展开完整 URL。
3. https 挂锁改用 `success` 绿色，与品牌色区分“安全”与“操作”。
4. 底栏随网页滚动隐藏（WebView 需开启 nested scrolling）。
