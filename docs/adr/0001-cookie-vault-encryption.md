# ADR-0001：Cookie 储存库使用 Keystore AES-256-GCM 加密，无损迁移

- 状态：已采纳（c7bcce2，7288fb1 加固）
- 日期：2026-10-17

## 背景
v1.6.x 及之前，储存库以明文 JSON 存在 `cookie_vault_storage/key_saved_cookie_records`。已有用户数据必须 100% 保留。

## 决策
1. 新增密文键 `key_saved_cookie_records_enc`，旧键只读兼容，不改名。
2. 独立 Keystore 别名 `cookiebox_cookie_vault_key`，与账号库分开，一方出问题不牵连另一方。
3. 迁移顺序：校验 → 加密 → 回读校验 → 单次 `commit()` 写密文并删明文；失败保留明文。
4. 解不开的密文逐份备份，之后每次读取尝试恢复并合并；损坏 JSON 备份后跳过坏记录。
5. 别名已存在时绝不重新生成密钥。
6. Keystore 不可用时降级明文写入。

## 后果
- 正面：静态数据加密；任何失败路径都不删除用户数据。
- 代价：首次读取有一次同步写；备份键可能累积（只有用户「清空」时删除）。
- 不解决：签名密钥公开导致的恶意覆盖安装风险（见 T-003）；root 设备。
